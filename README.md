# ☁️ Scalable Cloud Deployment & Disaster Recovery Blueprint

**Project Type:** Portfolio Project – Cloud Infrastructure & Business Continuity Design  
**Developer:** Laiba  

## 📌 Overview
Designed a secure, scalable, and resilient cloud architecture for a digital application using **Amazon Web Services (AWS)**. This blueprint ensures high availability, robust proactive monitoring, and a clear, step-by-step disaster recovery plan to minimize business downtime.

## 🛠️ Key Features
- **Multi-Tier Architecture:** Route 53 + WAF (Security) ➔ EC2 (Compute) ➔ RDS (Database) + S3 (Secure Backups).
- **Security & Compliance:** Role-Based Access Control (RBAC) and AWS Secrets Manager for credential safety.
- **Business Continuity:** Detailed Disaster Recovery SOP (Target: RTO < 2 Hours, RPO < 24 Hours).
- **Proactive Monitoring:** Amazon CloudWatch with automated SNS alerts for instant incident response.
- **Cost Optimization:** Estimated operational cost of ~$33.65/month for a small-scale, highly available deployment.
